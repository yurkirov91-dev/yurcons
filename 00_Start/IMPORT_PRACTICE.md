# Как принять вашу практику

Начать с 3–5 завершенных дел: ваша претензия, иск/возражения, экспертные материалы и итоговый судебный акт. Добавить описание результата и указать утвержденную вами версию.

Для каждого документа фиксировать: ID дела; вид; дата; автор; версия; стадия; фактическая модель; правовой вопрос; примененная редакция; результат; наличие последующей отмены; ограничения доступа.
Отдельно извлекать стиль (структура, формулировки, оформление), правовые приемы и доказательственные конструкции. Исходник остается неизменным; обобщение хранить рядом. Победа по делу сама по себе не подтверждает каждый аргумент и его применимость к новой ситуации.
Не заполнять базу автоматически всеми старыми вложениями: сначала выбрать материалы и проверить, что они относятся к нужному делу. Устаревшие образцы хранить с пометкой, не удалять и не применять молча.
После чтения подготовить реестр практики, образец стиля и предложение по шаблонам; спорные предпочтения согласовать с Михаилом. Это организация доступных материалов, не обещание постоянной памяти или обучения весов модели.
