# Процесс работы с делом

1. Прием: определить клиента, оппонента, предмет, даты, стадию, цель и ближайшее действие. Составить опись; сохранить оригиналы без правок.
2. Чтение: извлечь текст и сверить важные реквизиты с изображениями; у каждой выдержки сохранить страницу. У аудио — таймкод. Не подменять отсутствие текста догадкой.
3. Анализ: хронология, карта доказательств, спорные факты, бремя доказывания, недостающие документы. Отдельно — проверка экспертиз.
4. Право: выбрать применимую редакцию, открыть источники, проверить досудебный порядок и подсудность, сроки и возможные требования. Для срока фиксировать событие начала, норму, способ исчисления, выходные/праздники, подтверждающий документ. При неизвестном событии — только сценарии.
5. Стратегия: основной и запасной вариант; возражения оппонента; стоимость и доказательственные риски без выдуманных вероятностей успеха.
6. Проект: факты → доказательства → нормы → нарушение → расчет → просьба → приложения. Пробелы пометить явно.
7. Независимая проверка: реквизиты, арифметика, редакции, доказательства, исполнимость требований и комплектность.
8. Юрист утверждает финальную версию. Обновить STATUS.md и следующий шаг. Отправка/подача только по поручению.

Материалы конкретного дела хранить отдельно. .gitignore — удобство, а не механизм защиты или резервного копирования; принудительное добавление файлов может его обойти. Для GitHub предназначены инструкции, инструменты и обезличенные шаблоны. Проверять содержимое перед отправкой.
