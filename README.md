## Начать работу

Прикрепите документ или укажите доступный облачный путь и ID дела:
«Импортируй /workspace/yurcons/00_Inbox/заключение.pdf в дело 2026-001,
составь опись, хронологию и карту доказательств; выдели сроки и пробелы».
Вложения агент скачивает и импортирует самостоятельно. Windows-пути доступны
только в локальном Codex на соответствующем компьютере.
Подробнее: [работа по пути](00_Start/FILES_BY_PATH.md).

## Структура

- 00_Start — процесс, подключения, проверка настройки, приём практики.
- 01_Cases/<ID> — дела: оригиналы, извлечённое, анализ, проекты, утверждённые версии, судебные материалы, расчёты.
- 02_MyPractice — входящие образцы, утверждённая практика и стиль.
- 03_Templates — карточка, опись, хронология, доказательства, расчёты и структуры документов.
- 04_Knowledge — начальный каталог; исторические проверки не подтверждают актуальность нормы по делу.
- .agents/skills — пять юридических навыков в репозиторном формате Codex.
- agents/TEAM.md — координатор, исследователь, аналитик экспертизы, автор и независимый рецензент.
- scripts/import_document.py — импорт без перезаписи, SHA-256 и квитанция.
- scripts/setup.sh — проверка инструментов и подготовка русского OCR.
- scripts/Setup-Workspace.ps1 — сохранённый перенос на Windows; в целевой ОС не проверен. Не копировать клиентские материалы вместе с проектом.
